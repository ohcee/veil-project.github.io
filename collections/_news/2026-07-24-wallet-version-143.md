This OPTIONAL update [1.4.3.0 Veil core wallet update — download from Github](https://github.com/Veil-Project/veil/releases/tag/v1.4.3.0) brings a couple of nice improvements to the GUI (Graphical User Interface) wallet. If you have already installed PR1062 PR1064 or v1.4.2.0 or only use the Command Line Interface, then you do not need to install this release. The previous release v1.4.2.0 is the mandatory update.

We wish to thank the people involved in coding, testing, and reviewing this wallet, including but not limited to ohcee and Rock-N-Troll.

Updating the wallet software is as simple as replacing the program files veild, veil-qt, veil-cli, .... There is no need to touch your data files. Normal data backup procedures apply.

**Download Veil Core wallet v1.4.3.0 and read the full release notes [here](https://github.com/Veil-Project/veil/releases/tag/v1.4.3.0)**. Check our Veil support article for [how to update your Veil wallet](https://veil.freshdesk.com/support/solutions/articles/43000528762-how-to-update-upgrade-your-veil-wallet).

For any assistance, join the Veil community on [Discord](https://discord.veil-project.com) or refer to the Veil Knowledgebase at [https://veil.freshdesk.com/](https://veil.freshdesk.com/support/home)!
